# LearningEnglish Mobile

This is the Flutter app scaffold for phone and tablet.

## Current Scope
- adaptive shell with bottom navigation or navigation rail
- home, materials, upload, AI review, lesson detail, review, report, and profile entry pages
- demo repositories that mirror the backend contract shape
- theme and spacing aligned to the design system

## Notes
- Flutter and Dart SDKs were not available in the current environment during implementation.
- The code is scaffolded to compile once the SDK is installed and dependencies are fetched.
- Replace demo repositories with Dio + Drift backed repositories after the backend service is wired in.
