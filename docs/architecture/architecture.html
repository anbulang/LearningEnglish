LearningEnglish · 系统架构

拍照讲义 → AI 识别 → 家长校对 → 课程包 → 复习/口语 → 周报 · FastAPI 模块化单体 + Celery + Flutter + React

主链 Main Chain（讲义 → 周报）

  • ① 账号/孩子 — Mobile → /children → Postgres
  • ② 上传 CourseMaterial — /materials 多部件 → Object Storage
  • ③ OCR/解析 — Worker · Provider pipeline（DashScope/Doubao）
  • ④ 家长校对 — Mobile 轮询 → /material-jobs/confirm
  • ⑤ 课程包 — Worker 媒体回填 → KnowledgePack + ReviewTask
  • ⑥ 复习/口语 — PracticeSession · SpeakingAttempt（ASR 评分）
  • ⑦ 周报 — aggregate_weekly_report → /reports/weekly

边界与约定 Boundaries

  • • 家长端 /v1/*（Bearer JWT） vs 运维端 /v1/admin/*（X-Admin-Token + RBAC + 租户隔离）
  • • parent / admin / shared 模块边界由 test_engineering_boundaries.py 守护
  • • Worker 不得 import app.api；复用 services/shared
  • • 原始/生成媒体不入 Postgres，仅存对象存储，经 /uploads 提供
  • • 口语评分需公网可达音频 URL（DashScope 直接拉取）

Providers & 基础设施

  • • 默认 DashScope/Qwen：OCR · 解析 · 图像 · US/UK TTS · ASR 评分
  • • 备选 Doubao/Ark；可选 OpenAI（image/TTS）
  • • PostgreSQL 16 · Redis 7（broker db0 / result db1） · MinIO :9000
  • • Celery 队列 learning_english · 移动端 3s 轮询（无推送）
  • • 共享包 contracts/design_tokens 仅 Mobile 使用
