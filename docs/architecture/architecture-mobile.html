LearningEnglish · 架构（移动版）

拍照讲义 → AI 识别 → 校对 → 课程包 → 复习/口语 → 周报

主链 Main Chain

  • ① 账号/孩子 → /children → Postgres
  • ② 上传 CourseMaterial → /materials → Object Storage
  • ③ OCR/解析 → Worker · Provider pipeline
  • ④ 家长校对 → 轮询 → /material-jobs/confirm
  • ⑤ 课程包 → Worker 媒体回填 → KnowledgePack + ReviewTask
  • ⑥ 复习/口语 → PracticeSession · SpeakingAttempt（ASR）
  • ⑦ 周报 → aggregate_weekly_report → /reports/weekly

边界与约定

  • • 家长端 /v1/*（JWT） vs 运维端 /v1/admin/*（Token+RBAC+租户）
  • • parent/admin/shared 模块边界由 test_engineering_boundaries.py 守护
  • • Worker 不得 import app.api，复用 services/shared
  • • 原始/生成媒体不入 Postgres，仅存对象存储，经 /uploads 提供
  • • 口语评分需公网可达音频 URL（DashScope 直接拉取）

Providers & 基础设施

  • • 默认 DashScope/Qwen：OCR·解析·图像·TTS·ASR
  • • 备选 Doubao/Ark；可选 OpenAI
  • • PostgreSQL 16 · Redis 7（db0/db1） · MinIO :9000
  • • Celery 队列 learning_english · 移动端 3s 轮询
